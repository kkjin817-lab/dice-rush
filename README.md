# 다이스 러쉬 · Dice Rush · Prototype 08

Numbers War v12의 숫자 조합과 공격·방어를 주사위 3개 묶음 낙하로 확장한 별도 프로토타입입니다.
원본 numbers-war와 egg-rush는 변경하지 않았습니다.

## 실행

`실행.cmd`를 더블클릭하거나 이 폴더에서 `node server.cjs` 실행 후 http://127.0.0.1:8124 에 접속하세요.
Node.js가 필요합니다. 서버 창은 플레이 중 열어두세요. HTML 직접 실행 대신 HTTP 서버를 사용합니다.

## 규칙

- 1~6 주사위가 같은 확률로 등장합니다. 직선 또는 ㄴ자 묶음이 내려옵니다.
- 이동·회전으로 위치를 정합니다. 회전해도 각 주사위 눈은 유지됩니다.
- 착지한 세 주사위는 각각 아래 빈칸으로 떨어집니다. 투명한 주사위가 최종 위치를 보여줍니다.
- 같은 눈을 상하좌우로 눈 수만큼 연결하면 제거합니다. 2는 2개, 3은 3개…6은 6개 이상입니다.
- 가로 또는 세로로 연속 눈 3개 이상은 스트레이트입니다. 역순도 인정합니다.
- 스트레이트는 주변 한 겹, 1 포함 스트레이트는 두 겹(맨해튼 거리)을 함께 제거합니다.
- 1은 일반 연결로 사라지지 않습니다. 1 열 개가 연결되면 전체 보드 폭발입니다.
- 제거 후 낙하 → 다음 조합을 순서대로 보여줍니다. 최대 연쇄를 기록합니다.
- 같은 눈 연결 조합 하나당 해당 눈 수만큼 공격을 얻습니다. 2 조합은 2줄, 3 조합은 3줄, 6 조합은 6줄입니다. 같은 연결 덩어리가 기준보다 커도 한 조합입니다. 서로 떨어진 조합이나 후속 연쇄 조합은 각각 해당 눈 수만큼 얻습니다. 최대 10줄을 저장합니다. 스트레이트·주변 폭발·전체 폭발은 충전하지 않습니다. 스트레이트 폭발 범위를 제외하고 남은 주사위만으로 유효한 같은 눈 조합이 있는지 판정합니다.
- 공격 한 번당 상대에게 한 줄을 예약합니다. 발사 시점부터 3초 뒤 상대 맨 아래에 무작위 1~6 주사위 8개를 추가합니다. 추가 공격은 기존 도착 시간을 연장하지 않습니다.
- 공격 버튼을 한 번 누르면 한 줄을 보냅니다. 여러 줄은 여러 번 눌러 보냅니다. 길게 눌러도 자동 연사하지 않습니다. 가로 막대 10개로 보낼 줄 수를 표시합니다.
- 기존 고정 주사위가 위로 밀려 보드 밖으로 나가면 즉시 패배합니다. 넘치지 않으면 공격 줄까지 포함해 조합·연쇄를 판정하고 충전합니다. 단, 공격 주사위만으로 만든 같은 눈·스트레이트·1 열 개 조합은 발동하지 않습니다. 직접 놓은 주사위가 하나 이상 포함된 조합만 발동하며, 연쇄마다 이 조건을 다시 확인합니다. 유효한 스트레이트의 주변 폭발은 공격 주사위도 제거합니다. 공격 표식은 낙하 후에도 유지되며 과거에 받은 공격 주사위도 계속 공격 주사위로 취급합니다.
- 진행 중인 제거 연출은 해당 제거를 한 번만 확정하고 즉시 줄을 추가합니다. 예약된 공격은 각각 도착 시간이 지나면 처리합니다.
- 새 묶음이 생성 위치에 들어오지 못해도 패배합니다.
## 조작

| 기능 | 1P | 2P |
|---|---|---|
| 이동 | A / D | ← / → |
| 시계방향 회전 | W | ↑ |
| 빠른 낙하 | S | ↓ |
| 즉시 놓기 | Space | Enter |
| 한 줄 공격 | F | / |


AI 대전에서는 방향키와 Enter도 내 보드를 조작합니다. 화면 버튼은 마우스/터치로 사용할 수 있습니다.
Esc 일시정지. 창 포커스를 잃으면 자동 정지되며 계속하기 버튼으로 재개합니다.
2인 대전은 같은 PC의 한 키보드를 사용합니다. 온라인 대전은 없습니다.

## 튜토리얼

실전과 같은 엔진·화면·조작을 쓰는 8단계입니다.
이동/회전/분리 → 같은 눈 → 스트레이트 → 2연쇄 → 한 줄 예고와 도착 → 세 번 눌러 보내기 → 세 줄 상쇄 → 1 전체 폭발.
첫 단계 이후에는 필요한 버튼만 활성화합니다. 실패 부담 없이 규칙을 체험하도록 자동 낙하를 멈춥니다.
다시 해보기·건너뛰기·게임 배우기를 제공합니다.

## 검증

`node test.mjs`: 회전 눈 보존, 벽 충돌, 분리 낙하, 튜토리얼 구성, 순차 연쇄, 스트레이트, 전체 폭발, 조합별 눈 수만큼 충전과 폭발 충전 제외, 10칸 상한, 3초 뒤 공격 도착, 한 줄씩 상쇄, 연출 중 공격, 넘침 패배, 12개 시드 AI 대전.
브라우저에서 튜토리얼 이동·회전·배치·조합 성공을 확인했습니다.
실제 휴대폰, 두 사람의 동시 키 입력 및 난이도 밸런스는 추가 플레이 테스트가 필요합니다.

## 파일

engine.mjs: 묶음 조작, 중력, 단계별 연쇄, 공격·방어, AI.
rules.mjs: 기존 Numbers War 조합 판정 규칙(1~6).
lessons.mjs: 실전 엔진을 사용하는 연습 보드.
app.mjs / style.css / index.html: 화면과 조작.
sound.mjs: 브라우저 합성 효과음.

## 공격 알림 v07
보드 위 알림은 대기 중인 전체 줄 수와 가장 빠른 도착 시간을 표시합니다. 공격을 받는 동안 버튼은 붉은 1줄 상쇄로 바뀝니다. 한 번 누르면 저장된 공격 한 줄로 가장 먼저 도착할 공격 한 줄을 제거하며, 대기 공격이 없으면 상대에게 발사합니다. 보드 안에는 공격 예고 주사위를 그리지 않습니다. 일시정지 중에는 시간이 멈춥니다. 제거 연출 중에도 공격 도착 시간은 진행됩니다. 왼쪽 위 제목은 다이스 러쉬입니다. 상쇄 튜토리얼은 시간을 멈춰 연습하며 실제 대전은 3초입니다.
검증: node delay.test.mjs
